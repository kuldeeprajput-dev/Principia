# Lessons for subsequent agents

Inspect scientific file signatures: a DAT extension may contain MATLAB arrays. Distinguish simulated panels from measured panels and link multiple panels from the same source study. Preserve known published equations as strong comparators. Missing run and person IDs cannot be repaired by random row splits or by calling figure panels independent experiments.

Preserve the selected reference even when a later diagnostic model wins on exposed confirmation. Seek fresh whole-unit evidence before modifying admitted claims.
