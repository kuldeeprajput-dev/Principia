# Lessons for subsequent agents

Audit which covariates actually exist before describing geographical coverage. Carbon stocks leak bulk density algebraically and must not be independent predictors. Country-held-out failure can be scientifically informative even when a physically motivated curve fits development data. Do not infer a unit conversion from an inconvenient held-out distribution; preserve the source label and document uncertain country metadata.

Preserve the selected reference even when a later diagnostic model wins on exposed confirmation. Seek fresh whole-unit evidence before modifying admitted claims.
