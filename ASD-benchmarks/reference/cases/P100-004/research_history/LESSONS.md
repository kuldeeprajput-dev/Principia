# Lessons for later ASD work

The equation is an interpretable reconstruction diagnostic. Its components resemble established detector-resolution models, but shared reconstruction inputs prevent treating its predictive agreement as independent discovery of momentum conservation or new particle physics.

The source is a selected four-lepton sample without the Monte Carlo/control samples needed to identify background, missing particles or detector-resolution components causally.

Retain stronger simple/flexible controls, linked native groups and all negative results. Check measurement semantics before fitting. Correct implementation defects with dated receipts; never count retries as scientific attempts. Freeze selection before confirmation and never promote a diagnostic winner using exposed outcomes.
