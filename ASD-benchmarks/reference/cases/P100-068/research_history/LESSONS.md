# Lessons for subsequent agents

Resolve unit discrepancies before interpreting system-identification coefficients. Paired denoised traces are alternate representations, not independent confirmation. A constant-offset invariant model can be a stronger scientific control than immediately adding nonlinear force terms. Preserve original timing per trace rather than assuming every file matches the paper’s acquisition frequency.

Preserve the selected reference even when a later diagnostic model wins on exposed confirmation. Seek fresh whole-unit evidence before modifying admitted claims.
