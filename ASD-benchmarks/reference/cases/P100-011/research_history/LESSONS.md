# Lessons for later ASD work

This is a calibrated benchmark association, useful for assessing conversion between two evaluation modes. The fitted accelerator effect is not an identified coordination or hardware-efficiency law: platforms, software, precision and submitter choices are not randomized.

Reserved mean error is much larger than development error, reflecting difficult system-scale transfer. Several workload logits contact bounds; coefficients are not universal efficiencies. Offline calibration is mandatory, so this is not prediction from specifications alone.

Retain stronger simple/flexible controls, linked native groups and all negative results. Check measurement semantics before fitting. Correct implementation defects with dated receipts; never count retries as scientific attempts. Freeze selection before confirmation and never promote a diagnostic winner using exposed outcomes.
