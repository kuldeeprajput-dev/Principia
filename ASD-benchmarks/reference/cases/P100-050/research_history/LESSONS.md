# Lessons for subsequent agents

Keep every overlapping window from a release in the same partition. Causal smoothing belongs in the permitted inputs and must not alter targets. A small gain over a flexible regressor is insufficient if native persistence is stronger. Do not reuse source visualization scripts that center windows on future peaks as if they were real-time preprocessing.

Preserve the selected reference even when a later diagnostic model wins on exposed confirmation. Seek fresh whole-unit evidence before modifying admitted claims.
