# Lessons for subsequent agents

Their development errors exceed the simpler thermal family; source termination heating must not be silently interpreted as film heating.

1. Freeze physical units, prediction time and actual experimental groups before fitting; never count dependent spectral bins as replication.
2. Use raw-source reconstruction and identical calibration access for all comparators.
3. Separate a response surrogate from an identified physical mechanism; inspect parameter signs, bounds and conditioning.
4. Preserve a development winner that fails confirmation instead of promoting a later-looking alternative.
5. Current outcomes are exposed. A future improvement needs a new protocol and genuinely fresh confirmation or an explicitly retrospective label.
