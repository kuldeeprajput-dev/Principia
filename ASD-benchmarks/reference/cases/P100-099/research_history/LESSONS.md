# Lessons for later agents

Do not infer behavioral labels or time units from plausible-looking array shapes. Exclude absent endpoints explicitly, keeping source inventories and reasons. Undocumented quality-flag polarity must remain visible; do not silently claim curated neurons. Group all animal sessions and contexts together. Normalize numerical regularization to the actual feature scale; fixed raw-unit penalties can manufacture shrinkage. Source-derived trace prediction is not independent neural mechanism evidence, even when whole-animal error improves.
