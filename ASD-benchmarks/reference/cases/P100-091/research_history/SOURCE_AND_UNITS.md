# Native source and semantics: private standalone5G

The pinned TU Wien v1.0.0 record is DOI10.48436/hja53-s8y18. Bodur, Çağlayan, Demir, Poszvek and Bleicher measured seven indoor locations using iPerf2.2.1 during27June–3July2025. This package uses the existing local corpus bytes, not the later anonymized1.0.1 release. Dataset and README are CC BY4.0; source analysis code is MIT. Our reader does not execute source analysis code.

The target is the server-reported trial-average one-way delay in milliseconds. Offered and achieved throughput are Mbit/s. A trial lasts about60seconds. Seven locations each contain six offered rates and five repeats:210 runs. Three Q1/50Mbps trials have source-disclosed clock-wrap errors; they remain in the eligibility ledger with absent targets, and are never imputed. The207 valid trials constitute five development locations and two reserved locations, Q4/Q5. Source-derived fitted latency columns, NetPwr, delay dispersion, jitter, packet loss and TCP runs are not predictors. In particular NetPwr contains the target in its denominator.

Native logs contain BOM-marked UTF16, UTF8 and Turkish Windows CP1254 text. The first parser attempt failed on a CP1254 date label; the strict fallback was added before any fit. All extracted report fields use ASCII numerals and explicit unit conversions. Native ZIP members remain intact and no source files are rewritten. IP addresses are not copied into derived data; anchors retain only archive/member/report field.

Same-run achieved throughput is observable only after the trial, so this is conditional latency reconstruction, not an online pre-run forecast or an offered-load intervention model. No test-location mean delay is permitted as calibration. TCP capacity runs are omitted because some postdate UDP measurements. The complete network path includes campus routing/firewall, private5G core/radio, CPE and an802.11ax receiver link. No inference isolates radio delay or universal5G capacity. Clock synchronization was not independently measured here.

Source paper and source code already investigate linear serialization plus a queue pole, location offsets, whole-location validation and capacity identifiability. Their published fitted results are disclosed prior analyses, not discoveries of this campaign. Two Q1 schema examples were inspected; Q1 is explicitly development. Other confirmation scores remain withheld until freeze. Future benchmark use is retrospective once outcomes are published locally.
