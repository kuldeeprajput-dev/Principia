# Lessons for later ASD work

A proposed scalar degeneracy description is falsified: two development metrics have the same five distance ties and equality-normal rank3 but52 and54 facets. Restricting the exact construction to star trees also fails. These are precise finite counterexamples to tested simplifications, not a claim to a new classification theorem.

The catalog is small and source-selected. Descriptor regression is an approximation; independent exact constructions already achieve zero error. No inference to larger metrics or theorem-level novelty is claimed.

Retain stronger simple/flexible controls, linked native groups and all negative results. Check measurement semantics before fitting. Correct implementation defects with dated receipts; never count retries as scientific attempts. Freeze selection before confirmation and never promote a diagnostic winner using exposed outcomes.
