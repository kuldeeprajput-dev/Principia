# Lessons

1. Source-known gene association is not new mechanistic discovery. Select the endpoint before inspecting gene response; this avoids high-dimensional gene shopping.
2. One destructive donor calibration is substantive information. Give it equally to every comparator and exclude it from target scoring.
3. Whole-donor validation exposed fragile stiffness interactions. A development improvement may still fail the reserved donor. Preserve the selected state and report the retrospective comparator without promoting it.
4. A saturation parameter profiled over only three stiffness levels is an effective coordinate, not a uniquely identified binding constant.
5. One held donor supports only a bounded falsification. It cannot establish population reliability.
