# Choice-time semantics

Only Nasioulas2024_data.csv new experiments1–7 are admitted:540 participants. Older Erev2017 data are excluded. Current lottery outcomes/magnitudes are described in points; probabilities are fractions. The response is a recorded binary risky choice.

The original paper contrasts attitudinal and learning hypotheses and already reports increased risk taking with feedback. Those effects are prior art. Crucially, feedback availability is not announced at the first trial of some experiments. This adapter masks the current feedback flag until it is announced or observed. Previous reward errors use only displayed feedback; counterfactual regret is exposed only after complete feedback. Source-derived optimal choices and previous-outcome columns are not predictors. History is reconstructed chronologically inside participant/block, resetting to a declared neutral prior.

Participants, not trials, receive equal primary weight. Trial-history access includes prior target observations on the reserved participant, identically available to all comparators; this is sequential prediction and not zero-observation personalization. Future choices never enter an input. Lottery magnitudes and metadata were inspected before fitting; response values were not printed.
