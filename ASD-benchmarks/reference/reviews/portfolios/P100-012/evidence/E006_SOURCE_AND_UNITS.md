# Source and units

NIST hafnia-on-silicon reference-material campaign, DOI10.18434/mds2-3930. Local assets contain56RASspectra across12wafers and four deposition runs. Whole set has65ALDcycles per wafer. The RAS axis is TwoThetaOmega in degrees; q=4πsin((2theta)/2)/1.540593Å. Native intensity is counts, and each third-column correction factor must equal1.

Calibrated higher-angle prediction uses a fixed five-point band near2theta1degree. All raw bytes are unchanged; targets are everytenth native sample in1.4–4.8degrees. Source-fitted SE thickness and roughness images are not independent labels.
