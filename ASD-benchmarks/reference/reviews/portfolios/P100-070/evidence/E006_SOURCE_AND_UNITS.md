# Source and units

Gong et al., Zenodo14776881 and JGR2025JB031286. Source README maps CSH_FOV5 to specimen119DOA and CSL_FOV4 to129DOA. Bz is retained as the measured magnetic-map product. No conversion from its native numerical scale to tesla is assumed because local metadata do not resolve that mapping. Pixel offsets are used for geometry; no unverified physical-distance conversion.

Author temperature profiles, inverted parameters and posterior samples are not independent measured thermal targets. The README lists uz0 filenames while the distributed files use uc0; actual names are frozen verbatim.
