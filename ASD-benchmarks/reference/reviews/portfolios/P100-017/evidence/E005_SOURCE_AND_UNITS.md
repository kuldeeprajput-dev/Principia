# USGS location uncertainty

QuakeML origin.depth.uncertainty is in metres, converted to km; this is supplied formal/reporting uncertainty, not measured error against independent true depth. RMS phase residual standardError is seconds. usedPhaseCount/stationCount are counts; minimumDistance angular degrees converted with111.195km/degree. Network reference depth conventions differ and negative depths are permitted. Positive finite uncertainty/RMS/count criteria exclude zero/fixed/undefined precision reports; no imputation. Models concern diagnostics of author estimates and cannot validate hazard or physical source laws.

Groups are transitive connected components under100km chord distance and7days (coordinates/times only). Earthquake swarms and aftershock sequences stay linked. Cross-network velocity-model dependencies remain. The one-month global source has no reserved future earthquake event and no causal intervention.
