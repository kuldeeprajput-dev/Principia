# Source and units audit

The source contains electrical(SMU current/voltage) and optical(photodiode current) records and context images/projects. The task uses the Backlog_Statistic_Stretchable_LEC folder only; duplicated featured traces in Stretchable LECs are not double-counted. Device ID combines polymer fraction and device number; all voltage runs and `_2`records stay linked. Source17devices yield15eligible devices after the frozen early-calibration rule; two extremely short devices contain no eligible post20s endpoint. These remain documented exclusions, not discarded unfavorable long records.

Native headers specify seconds, amperes and volts. Optical targets are **signed photodiode current in nA**. No absolute-value operation, log filter or conversion to luminance is used. The source luminance formula needs stretched area and optical correction; complete per-row strain/area information is absent. A strain law cannot be identified from these files alone.

The ISO timestamp lines define clock segments. Two optical files contain an embedded ISO timestamp and elapsed-time restart; each segment is reconstructed from its own ISO time. Device electrical current is joined using the latest reading no later than the optical timestamp, at most2seconds old. Cumulative charge is trapezoidal current integration only through that electrical reading. Raw file rows are retained as anchors; instrument `Absolute time` has session-specific origins and is not used across SMUs.

The predictor receives the median optical current over aligned0..20s and the median electrical current first20s of each run. No optical response after20s is supplied. Fourdevicegroups are reserved;11eligibledevelopmentgroups are leave-one-device-out. Optical calibration is an explicit budget, not an unseen-device claim. Signed data, device failures and long-run drift remain in evaluation. Absolute timestamp convention is assumed consistent between twoSMUexports; residual alignment uncertainty is a limitation.
