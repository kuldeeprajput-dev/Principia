# NVD snapshot semantics

Target is an exact descriptive annotation-presence predicate, not vulnerability severity/exploitation. Both primary and secondary CVSSv3.1 assessments are inspected by source field; only nvd@nist.gov marks the endpoint. Non-NVD score availability is a separate permitted observation. Rejected records excluded. Source-day publication count uses all non-rejected snapshot records without outcomes; includes other CVEs within held source as allowed metadata. No future-update timeline can be reconstructed from a single recent feed. Public schema audit saw aggregate status counts; statuses are not predictors. April2026 NIST policy stopped routine duplication of CNA scores and changed modified/deferred workflow; do not treat every missing NVD score as an enrichment backlog failure.
