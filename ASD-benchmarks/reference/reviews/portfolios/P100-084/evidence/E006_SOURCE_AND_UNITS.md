# Source and units

FORTH/DESY AFM characterization, Zenodo20281797; 13 exported paired force-distance curves from flat, low-roughness and high-roughness cellulose acetate. ForcepN is converted tonN by1/1000; source calibration lists springconstant20.75N/m and deflectionsensitivity86.5nm/V. Probe-radius16.5nm/DMTanalysis are authorcontext, not targetlabels.

Task reconstructs laterretraction using explicitly permitted completedapproach and initialretraction calibration. Measured deflection at the target row is forbidden because force is a calibrated multiple of it. Nativepiezo position is normalized using a fixed5nNapproachcrossing; this does not identify true indentation.
