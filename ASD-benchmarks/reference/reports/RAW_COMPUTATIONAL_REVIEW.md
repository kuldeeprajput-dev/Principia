# Native reconstruction: computational review

This review concerns the deterministic preparation of the 54 registered task versions, rather than the novelty or industrial significance of their scientific claims. All archived outcomes are exposed for future use. Reproducing source measurements is a prerequisite for evaluation, not confirmation of a new scientific law.

## Implementation boundary

The preparation API reads only hash-verified raw assets, explicit optional source folders, frozen split identifiers and two declared learned-state records. It does not read historical prepared tables, fit candidates, tune hyperparameters, download data or modify native bytes. Frozen benchmark tables are opened only by the separate reconstruction verifier as expected outputs.

Native observations and supplied author processing remain explicit: instrumental coefficients, calibrated radiomaps, spreadsheet-derived outcomes and prior completed response histories do not become independent experimental evidence merely because a parser reproduces them.

The shipped source-derived ports remove campaign execution, scientific fitting and historical output writes. The parent evaluator verifies its code manifest before importing adapters. The preparation manifest separately records every native reader, metadata inventory and frozen calibration state.

## Scientific distinctions retained

- Original 25 tasks preserve their targets and exposed evaluation cohorts. All numeric inputs, targets, identities, grouping and retained source anchors are checked against their archived packages.
- The fifteen second continuations remain development-only task versions. HPLC residual sugar is distinct from qPCR percentage; additional historical rheology and radio/thermal measurements remain declared input changes.
- The ten latest continuations retain separate calibrated slag, empty-flow wind, causal weather-history, fermentation-history and corrected cycling contracts. They are not treated as fair same-information improvements over older tasks without their declared additional inputs.
- The four supplemental PLA response tasks use two native commercial-material archives. Storage and loss remain separate outcomes. Their previous confirmation history remains historical; their results are now exposed.
- Corrected case 96 requires its pinned earlier-stage annotation files explicitly. The core original cycling task continues to reconstruct from the original benchmark source archive.

## Learned preprocessing and calibration

Case 61 pure-hydrogen calibration coefficients are copied as frozen fitted parameter state with the original source-state hash and training scope. They are not re-estimated from evaluation responses. Case 60 scoring normalization is copied per outer fold from the recorded training-condition scale with its training groups and validation IDs. It is an evaluation denominator, not a numerical predictor.

Other calibration records are deterministic summaries of explicitly permitted observations: early-cycle stiffness, completed prior screw operations, age-zero force traces, earlier rheology/sugar/gas observations, initial lubricant temperature and initial radio calibration. The generic calibration output excludes current scored targets. Core scenario preprocessing that is learned by a reference model remains inside that model's frozen state.

Case 82 has both source grouping and forward-fold evaluation grouping. Its reconstructed anchors retain the source group; scoring uses the separately frozen evaluation group. Temperature and moisture history use strictly earlier native site dates within 30 days.

## Verification interpretation

`RAW_RECONSTRUCTION.json` is the definitive execution receipt, with per-task, per-column results and hashes of the expected benchmark tables. Numeric values use float64 tolerance 1e-11 with identical missingness. Identifiers and source metadata require exact equality. Deterministic regenerated gzip containers need not match historical gzip bytes or historical decimal formatting.

`RAW_INVARIANTS.json` records source-mutation rejection and causal-prefix falsifiers for screw torque, microplastic upstream motion and CHO sensor summaries, including quality flags. These are computational properties; they do not establish independent laboratory replication.

The final receipt reports 54 successful task reconstructions: 49 core tasks and five explicit supplemental tasks across 25 scenarios. The check compares 754 columns over 307,478 task rows, including exact identifiers and metadata. All eight invariant checks pass. Earlier disposable tests uncovered and corrected the case 24 nonpositive-stiffness flag, the case 71 source-cell/timestamp-envelope presentation, and alternate-task schema additions. Those fixes alter parser packaging or explicit preparation bookkeeping, not model coefficients or scientific results. Earlier test artifacts remain in local operational history.

## Limits

The eligibility output identifies membership of reconstructed measurements in a declared task cohort. Native source exclusions remain governed by each source parser and scenario's scientific contract; a missing source record is never silently assigned a numerical zero. This release cannot turn already public/exposed outcomes into fresh validation. Supplementary-rights eligibility is decided by the benchmark's per-asset release register, not by successful numerical parsing.
