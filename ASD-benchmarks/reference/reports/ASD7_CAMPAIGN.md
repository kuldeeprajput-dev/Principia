# Completing the 100-scenario exploration corpus

The final 45 scenarios have completed **267 substantive investigations**: 262 predictive/mathematical investigations and five source-adequacy investigations. One invalid implementation in case 62 remains archived but is not counted. The campaign adds 44 numerical tasks,450 model/task comparisons and 114 finding records. Baseline/reference aliases and protocol aliases are comparisons, not independent discoveries.

## Scientific reading

Useful scoped results include calibrated X-ray interference (12), causal complaint-count forecasting (19), pilot-calibrated compiler runtime ratios (31), completed-trip duration (40), burst count-space response (45), finite-pulse battery relaxation (49), current-conditioned hydrogen permeation (62), calibrated AFM adhesion (84), paired-well fluorescence (93), and processed calcium-trace forecasting (99). Their applicability differs: these are not a league table or certification of new fundamental laws. Case 31 improves relative error while worsening absolute seconds error; case 49 improves MAE while losing some tail-error comparisons.

Failed extensions are equally visible: gait/pupil/EDA persistence wins (7/9/80), soil/crowd/neural-donor transfer fails (81/97/75), and the graph task has a constant target for which perfect prediction is trivial (5). The single-patient imaging subset (8) supports a scientific abstention with an executable source-adequacy evaluator. No diagnostic accuracy is invented.
