## Exact corpus scope

There are 100 catalog cases: **55 explored and evaluator-equipped, 45 pending**. The local registry contains **91 task versions and 931 model/task comparisons**: 86 original-corpus contracts and five explicit supplemental contracts. Seven documentation-corrected v2 versions repeat 90 unchanged scientific comparisons; these are not new experiments or discoveries. The twenty new scientific tasks add 208 comparisons. The local portfolio contains **138 finding records** including reproductions, extensions, falsifications and limitations.

The public-ready projection excludes the unresolved optional corrected cycling task and its detailed numerical data: **90 tasks, 912 model/task comparisons and 137 finding records**. The original cycling scenario remains. Native source data are referenced under the original corpus and not duplicated in this scientific result layer.

## Corrections and scientific boundaries

Cases 57, 60, 61, 72, 83, 92 and 100 receive documentation-only v2 task contracts correcting inherited calibration, endpoint or cohort descriptions. All native values, model coefficients, group allocations, predictions, scores and original v1 task packages remain unchanged. The registry explicitly directs current submissions to corrected contracts.

Boolean reconstruction comparison is repaired; case 53's event label and case 65's logarithmic error units are clarified. Probability scoring and task-specific diagnostics are separately versioned additions. Core existing numerical metric semantics remain 3.0.0-rc.1; extensions are asd6-diagnostics/1.0 and asd6-probability/1.0. Corpus version is 3.2.0-rc.1. [Environment](ASD6_ENVIRONMENT.json) records exact tested dependencies.

The strongest new results are bounded predictive extensions. No universal new physical law, independent laboratory replication, clinical benefit or deployed industrial savings is certified. Mechanistic alternatives, weak parameter identification, small group counts and information-release limits remain prominent. Later confirmation winners did not replace development-selected references. Case 85 retains its earlier full target-exposure disclosure. Every current outcome is now exposed; future validation on these same observations is retrospective.

Checks cover registered task assets and the explicitly inventoried prior scientific layer, not every operational cache or an exhaustive sensitive-content detector. Historical missing training scopes and unresolved supplemental rights remain visible. All prior 35 scientific portfolios are preserved. The [handoff](../docs/ASD6_HANDOFF.md) explains how future agents should continue without weakening these standards.
