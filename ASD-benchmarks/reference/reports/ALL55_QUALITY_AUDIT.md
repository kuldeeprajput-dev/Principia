# Quality audit of all 55 explored scenarios

Every explored portfolio was inspected for evidence, target semantics, calibration, timing, independent units, baseline strength and claim scope. The prior 35 received a targeted new audit; the 20 new portfolios received separate computational and scientific-critical reviews. All registered numerical tasks are covered by native reconstruction, portable replay and independent metric checks.

## Changes that improve benchmark quality

- Seven older continuation contracts now have explicit v2 descriptions: **57, 60, 61, 72, 83, 92 and 100**. These correct inherited static-calibration, endpoint or reserved-cohort wording. All scientific assets and v1 packages remain unchanged; v2 is not new evidence.
- Boolean native values are now compared as Boolean values before numeric tolerance logic. A verifier type error affecting cases 21, 51 and 64 is fixed and tested against value/type mismatches.
- Case 53 event labeling correctly says angle-mean forming torque. Its threshold arithmetic did not change. Case 65 logarithmic error is labeled dB; ordinate reference-density units are not error units.
- Probability endpoints now receive equal-group Brier score, log loss, calibration bins and event diagnostics. Complete event failure has F1=0 when its denominator is positive; undefined cases retain reasons.
- New scientific diagnostics test bounds, calibration windows, monotonicity, paired formulation decisions and declared temporal ordering. These do not turn predictive fits into physical laws.
- All portfolios now have a current quality overlay and task-version navigation, while their original scientific evidence remains preserved.

## Limits of this validation

Reproducing recorded values and model outputs checks computation, not independent experimental replication. Historical missing training-membership records remain explicitly unresolved; the audit does not invent them. Small group counts, one-system experiments, known source analyses, prospective-information gaps and fully exposed outcomes restrict scientific claims. Case 58 retains 35 assigned challenge readings but only 32 positive targets eligible for logarithmic scoring. Missing or excluded rows never become zero-error observations. Case 85 remains explicitly retrospective because all four scored targets were visible during schema inspection. See the acceptance receipt for exact executed checks and the research handoff for future campaign rules.
