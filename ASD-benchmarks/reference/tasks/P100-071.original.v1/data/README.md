# Inputs and observations

Source: [authoritative dataset record](https://zenodo.org/records/20829178). Identifiers: 10.5281/zenodo.20829178. Source terms: cc-by-4.0. Exact source-asset hashes and URLs are in `../rules.json`.

`inputs.csv.gz` contains only declared prediction-time features and identity columns. `observations.csv.gz` separately contains held-out responses, group identifiers and native source/sample anchors. These are derived analysis tables from the earlier frozen campaign; source data remain unchanged. `../evidence/predictions.csv.gz` holds the original saved prediction values for the packaged models.

VCD target: million cells/mL; source SEM is retained separately. Permittivity/DeltaEps: pF/cm; conductivity: mS/cm; fc: kHz and `fc_mhz=fc/1000`; transmission/reflection: source arbitrary units; C(f) readings: source units not independently specified. CO2/DO: source saturation percentages; pH dimensionless; temperature °C; agitation rpm; aeration standard L/h; volume L; age hours. RBF features include causal 24 h lags, elapsed-hour derivatives, prior-only maxima and explicitly named products. Optical density is -ln(transmission); nonpositive transmission becomes missing. Predictor NaNs are preserved, then handled by frozen development medians and missing indicators. `deltaeps_fc4=deltaeps*fc_mhz**4`, `perm_fc=perm*fc_mhz`, decline=max(0,past_peak-perm), fractional decline=decline/max(past_peak,0.1), `perm_x_conductivity=perm*(conductivity-12)`, `perm_x_growth=perm*dperm24`; other squared/product features use their named operands. No future culture peak or future target is used.

Prepared input columns: `perm`, `deltaeps_fc4`, `transmission`, `reflection`, `conductivity`, `deltaeps`, `fc`, `cole_alpha`, `c300`, `c1118`, `c9995`, `cole_r2`, `co2`, `ph`, `do`, `temperature`, `agitation`, `aeration`, `o2_inlet`, `volume`, `perm_lag24`, `transmission_lag24`, `perm_peak_past`, `fed_batch`, `od`, `dperm24`, `dod24`, `spectral_span`, `spectral_midspan`, `fc_mhz`, `permittivity_decline`, `perm_decline_fraction`, `od_sq`, `perm_sq`, `perm_fc`, `perm_x_decline`, `perm_x_conductivity`, `perm_x_growth`, `od_x_decline`, `time_h`.

All preprocessing and prior analyses were source-aware. The paired/grouped holdout was respected during the original campaign; these responses are now exposed. The final script only replays fixed parameters. Original acquisition/source audits and row-level timing evidence are preserved in research history.
