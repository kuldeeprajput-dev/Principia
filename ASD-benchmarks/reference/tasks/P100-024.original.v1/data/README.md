# Prepared reference inputs and observations

These are derived analysis products, not untouched native instrument files. Original source bytes remain in the scenario source corpus. `inputs.csv.gz`, `observations.csv.gz` and saved predictions have the same stable `sample_id`, whole-group `group` and row order. Source filename and exact native row/XML record anchors are retained. Predictors are declared in `rules.json`; sample identifiers and target values are not predictors.

Target: finite positive author-extracted `StiffnessAvg [GPa]` at cycles>=1000. `native_target` preserves every finite source value, including nonpositive extracted values; `target_quality` labels eligibility and `target` is missing for nonpositive values. No high-positive readings are removed from primary scoring. Each specimen permits only median finite stiffness from cycles10–20 as early calibration (`E0_GPa`). `strain_percent` is native E-max[%] nominal metadata, not future measured strain. Cycle, frequency and cure are declared metadata; no failure time, fraction-of-life, post20 measured stress/strain/stiffness or source SN coefficients are predictors. Raw logger sampling is adaptive; primary means are over native recorded rows, not uniform cycle-time integration. Cycle-interval weighting is a separate sensitivity.
